# DIGEST — reviewer ideas against v36h

Baseline: L=3.815473322483099e-5, A≈0.5016415. This is a research digest, not a new circuit result. The [owner-supplied ledger](src/OWNER_BRIEF.md) gives round-only 30.432 µ and a pre-round difference of 7.723 µ; region-removal gains overlap. **µ=1e-6 of loss; positive savings mean lower L.** A noiseless-region experiment is not a universal bound on a redesigned postselected circuit ([F], “Terminal class floor”; [R11], terminal audit).

## 1. Five priorities

The order is my qualitative judgment of expected return on v36h, including implementation risk. Numerical targets below are **inferred planning scenarios, not forecasts or demonstrated gains**; every unbuilt combination can lose. GLOBAL already owns the 2.705 µ joint phantom opportunity; its on-grid work is excluded from these new tests ([P]; `GLOBAL/BRIEF.md`, `GLOBAL/room/prices.txt`).

1. **State-specific 15-T completion + release-profile archive + a global model containing r3.** Replace TREP2's mandatory routing reversal, jointly choosing output placement and the next check; preserve prefixes that release useful cells even when their fixed-suffix score loses ([R4] #5; [R12] #2–4; C27/C33/C71/C72). This can change the occupancy assumptions behind EARLY/R43, whereas polishing the early prefix alone addresses only the supplied 2.10 µ diagnostic. A **1–3 µ net target** would recover 13–39% of the 7.723 µ pre-round difference; no evidence yet establishes that recovery. First decisive test: fixed-variable round-trip of all v36h roles, records, guards and r3, then one 4–6-wire completion window; retain 20–50 release profiles and build three downstream completions. Cost estimate: 1–2 days implementation, one ≤4-process solver-hour per window, then tens of whole-circuit prices. This extends upstream of GLOBAL's present helper-placement brief. Evidence reopening it: `FRESH/REPORT_prior_architecture.md` §§Global/Warm-started explicitly says the old independent-encoder model cannot represent the correlated incumbent; `EARLY/REPORT.md` closes fixed-prefix placements only.
2. **Joint A encoder–data guard–partial decoder, with transient encoded flags.** Let a borrowed encoded wire carry an error trace that a later deterministic parity reads; optimize the complete process across q14/q16's guard slots instead of preserving three module boundaries ([R7] M06; [R11] Task 5; [R12] #6; C17/C47/C74). A **0.5–1.5 µ target** is plausible only by addressing both A masking and data exposure: the supplied A-region diagnostic is 1.64 µ and the data-wait diagnostic 3.88 µ, **not additive**. First test: reproduce current A,N with a sufficient input/output/record boundary, then synthesize one 4–6-wire cross-boundary witness and price all removed guards/new idles. Cost: 4–8 hours boundary/builder work, a small solver run and ≤100 prices; boundary growth could dominate. AENC's exact optimum is on **v36c's A-only boundary**, and FLAG's two-gap theorem fixes roles/depth/couplings; neither settles this process (`AENC/REPORT.md`, `FLAG/REPORT.md`).
3. **Joint B/C verification instrument with an earlier encoded flag and complementary readout.** Search a branch-aware meter during preparation, retaining the immediate pre-use check, and synthesize its resource/readout together ([R8] R06; [R9] M07; [R11] Tasks 4,6; [R12] #1,5; C55/C63/C69/C70). The supplied B/C diagnostic is 3.81 µ; **0.5–1 µ is a test target**, not a measured saving. Direct R102 supplies a concrete warning: its matched perfect-prep advantage is **0.822 µ, reviewer-reported**, but six actual BCX witnesses lose, best L=4.891268e-5, A=.49659 (`BCX/HANDOFF.md`, `BCX/results.json`). First test: consume BCX's existing run results, then price independent ideal meters at three r3 cuts and synthesize only one meter with useful information; compare complete Jτ=A(L−L₀), including copy displacement and acceptance. Cost: 4–8 hours instrument work plus tens of prices; a successful meter then needs a small synthesis campaign. The 2,676 terminal-CX negative screen does not cover earlier branch-aware instruments ([F], “C is the cheapest B checker”).
4. **Rank-six phase routing with explicit holder protection and state-specific completion.** Screen 22-T supports, and the **31-T pair-protected supports hidden in the certificate**, for a better route/release interface ([R12] #7, `code/rank6_phase_audit.py`, `receipts/rank6_phase_certificate.json`; C75/C76). Reviewer-reported: 39,928 minimal 22-T supports, phase-only loss .335 µ; 32,768 minimal 31-T supports have zero target-XOR pairs. Neither has a full noisy build; 31-T still needs signs/Clifford completion and both need a real sixth-coordinate flag. **Net gain is unquantified**; without an O(1 µ) routing/release benefit this ranks poorly against #1. First test: route a small diverse support sample, certify the full accepted state and holder×suffix fault response, and reject T14's failure mechanism before extending the >20-T evaluator. Cost: about one day for the first routed/fault-screened witness; evaluator extension is a separate 1–2-day risk. T14's 1.73e-4 result used v36c's suffix and does not prove these rank-six families impossible (`T14/REPORT.md`).
5. **C-free post-use verification + partial decoding/output handoff; then a different terminal class.** Combine the certified accepted A/B instrument with only the inverse parities actually needed, moving checks or changing output ownership to avoid a long terminal wait ([R7] M07; [R4] #2; [R8] R10; C31/C48/C58). **No credible net estimate exists.** Within the measured-partner class, L₀−22.74 µ=15.415 µ is only a floor-based ceiling; crossing that floor requires changing the final instrument, and the any-circuit 11.62 µ floor still binds ([F], floor rows). First decisive test: two or three explicit latency-respecting suffix templates on the current boundary, with arbitrary-state/record relaxation followed by a realizable ideal witness. Cost: 1–2 days for a small instrument prototype; broader synthesis/evaluator work only after it survives. The naive full inverse's ≈210 µ loss is a measured old-layout failure; its artificial one-idle ≈20.2 µ diagnostic is **not achievable evidence** ([R7], architecture §4). A syndrome-dressed known-T check is a more speculative branch; raw late W projection is already refuted (C49/C50).
