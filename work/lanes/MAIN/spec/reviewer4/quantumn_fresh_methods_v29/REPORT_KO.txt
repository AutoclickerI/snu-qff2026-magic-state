후보 1 — 측정 보조선을 이용한 비연결 B/C 준비와 지연 검증
------------------------------------------------------
핵심: B와 C를 직접 이웃시키고 C 준비를 먼저 끝내야 한다는 조건을 완화한다.
보조선 h를 |0>로 준비하고 CX(B,h), CX(h,C), MX(h)를 하면 원격 CX(B,C)가
구현되며, 알려진 부수 효과는 MX 결과 m에 따른 Z_B^m이다. B가 나중에 X로
측정되면 그 결과를 XOR하여 검출식에 흡수할 수 있다. 출력 데이터에 임의의
물리 Pauli frame을 허용하는 편법이 아니다.

일반화: k개 control parity를 h에 모으고 l개 target에 전달하면 2k+l CX의
coherent uncompute를 k+l CX와 MX로 바꿀 수 있다. (k,l)=(1,1),(2,1),(2,2),
(3,1)의 모든 측정 분기 Kraus 항등식을 직접 확인했다.

검증 라운드 파이프라인:
  R:   D->A 와 B->h
  R+1: A 측정, B->D 와 h->C
  R+2: B의 MX, h의 MX, C의 MZ
B 검증 정보는 먼저 복사하고 C 검증은 B가 데이터에 쓰인 뒤 마무리한다.
동일 R의 직접 검증과 데이터 사용 시각/전체 깊이는 같다. C를 먼저 h로
이동시켜 검사하는 순서에 비해 C 준비 완료 시점에 두 tick의 여유를 준다.
일반적인 1-CX C teleport+check와 비교하면 CX 개수 이득은 없다.

실제로 만든 전체 회로의 전차수 결과(옛 v11 prefix, 격자 제약 완화):
  direct R33: 1-F=3.556443370461517e-5, A=0.67276189756
  direct R34: 1-F=3.639747146977817e-5, A=0.66808900950
  bus    R34: 1-F=3.757640397440119e-5, A=0.65517172207
  direct R45: 1-F=4.968527831308431e-5, A=0.61888103739
  bus    R45: 1-F=5.196183007523354e-5, A=0.60693629107
R34에서의 순수 추가 비용은 1.1789325e-6이다. 노이즈가 더 좋아진 결과가
아니라, 이동·대기 비용을 줄일 수 있는 자유도의 가격을 측정한 것이다.
라운드의 동시 점유는 35셀이고 prefix의 q19까지 합친 전체 회로는 36셀이다.
이상적 정확성/유해 단일 오류 검사를 통과했지만 유효 6x6 배치는 아직 없다.

새 기하학적 제한: 연결된 7셀 B의 각 셀에 서로 겹치지 않는 두 외부 이웃을
배정할 수 없다. 전수조사 7,816개 중 지역 degree 조건 통과 656개, 최대
matching 13, 필요한 14를 만족하는 경우 0개. 짧은 증명: B 내부 degree<=2
이므로 7정점 path다. 내부 5정점은 격자 내부 4x4에 있어야 한다. 그 5정점
중 꺾임은 두 내부 정점이 같은 외부 모서리 셀을 강제로 공유하게 하므로
불가능하다. 5정점 직선도 4x4에 들어가지 않는다.

첫 실험: 최종 B/C 셀은 비연결로 허용하고, 측정 clean bus로 encoder를
합성한 뒤 같은 보조선을 재사용한다. B/C 내부 CX encoder에서 생긴 알려진
Z 부수 효과를 최종 B readout까지 추적한다. 접점이 필요한 모든 시점의
실제 점유와 noise를 확인한다. 기존 routing 비용 절약이 bus의 비용보다
작으면 종료한다. 35셀이라는 개수만으로 배치 가능성을 주장하지 않는다.
증거: preparation/instrument_identities.*, bus_*.qasm와 결과,
architecture/two_ports.*.

후보 2 — 최종 syndrome check와 부분 데이터 이동의 결합
-----------------------------------------------------
표준 쌍: CX(D,A); MZ(A), D를 출력으로 유지.
이동 쌍: CX(A,D); CX(D,A); MZ(D), A를 출력으로 유지.
두 측정 분기의 Kraus 연산자가 출력 위치 재명명 후 정확히 같다. D,A가 다른
계와 얽혀 있어도 성립하며 물리 frame을 추가하지 않는다.
7개 중 아무 부분집합이나 이동 가능하므로 128개 출력 마스크가 새 변수다.
check+literal SWAP의 4CX를 2CX로 줄이는 것은 보장된다. 정지한 check와
비교하면 1CX가 늘어난다. 별도 이동+check와의 절감은 실제 endpoint가
일치하는 경우에만 주장할 수 있다.
검증: 2x4 Kraus 행렬, 128 masks x 2^14 입력 = 2,097,152개 basis case.
기존 prefix의 q4/q10 교환과 다른 점: 마지막 Steane check에서 실제 출력
셀을 선택한다. 현재 A와 B의 checkerboard 배치는 이동 후 다른 check의
인접성을 깨뜨릴 수 있으므로 v29c에 단순 삽입하는 방법은 아니다.
첫 실험: ENDSTATE에 retained-output mask를 넣고, 필요한 위치만 이동한다.
추가 CX의 손실보다 실제 routing/idle 감소가 작으면 해당 마스크를 닫는다.
증거: architecture/moving_check.*.

후보 3 — dirty bus를 개별 CX가 아닌 parity rectangle 단위로 사용
------------------------------------------------------------
서로 겹치지 않는 control 집합 a_i, target 집합 b_j, 임의 상태의 h에 대해
A=product CX(a_i,h), B=product CX(h,b_j)를 정의하면 시간 순서 A,B,A,B는
모든 i,j의 CX(a_i,b_j)를 구현하고 h를 정확히 복구한다. h가 외부 계와
얽혀 있어도 같다.
격자의 degree-4 별 구조에서 2 controls x 2 targets는 4개의 원격 CX를
각각 4CX bridge로 구현할 때의 16CX를 8CX로 줄인다. 1x3도 12->8CX다.
새 검색 단위는 단일 edge가 아니라 GF(2) 행렬의 rank-one rectangle이다.
비연결 encoder를 만들 때 다른 block의 살아 있는 셀을 경유할 수 있다.
이상적 항등식과 CX 절감은 전수검증했으나 bus fault의 상관 전파 때문에
충실도 절감은 보장하지 않는다. 우선 disposable checker를 bus로 쓴다.
첫 실험: encoder/transfer 네트워크에서 2x2 rectangle을 추출해 대체하고
유해 단일/쌍 오류를 평가한다. gate 수 감소가 correlated hook 손실보다
작으면 그 macro를 폐기한다.
증거: architecture/dirty_bus.*.

후보 4 — B를 항상 |0_L>로 준비하지 않는 논리 분기 공변 B/C 합성
-----------------------------------------------------------
이상적 구성: B=|+_L>, C=|0_L>, transversal B->C, C의 Z 측정.
C의 zero-syndrome word의 parity b에 따라 B는 |b_L>가 된다.
B->D의 알려진 논리 X^b는 허용된 FRAME_X로 보정할 수 있다.
16개 C 측정 분기가 각 1/16이며 조건부 B와 frame 등가를 직접 검증했다.
이것은 임의 물리 Pauli frame을 사용하는 제안이 아니다.

중요한 새 fault contract: X-error patterns e_B,e_C에 대해 H e_C=0인
accepted 분기의 위험은 ell(e_B) XOR parity(e_C)로 결정된다. 여기서
ell(e_B)=parity(e_B) XOR [H e_B != 0]는 judge decoder의 논리 X다.
서로 맞는 B/C의 논리 X는 encoded Bell stabilizer이므로 무해할 수 있다.
반대로 독립 C logical X는 잘못된 frame을 만들고 T-state loss 1/2를
일으킨다. 기존 parity detector만 삭제하는 방법은 잘못이다.
첫 실험: BCPOL의 endpoint를 고정 상태가 아니라 이 joint instrument와
fault predicate로 바꾸고, 모든 Pauli/측정 분기에 대해 확인한다. 기존
encoder를 단순히 한 초기화만 바꾸는 shortcut은 확인되지 않았다.
추가 frame readout 보호 비용이 합성 절감을 없애면 종료한다.
증거: preparation/instrument_identities.* 및 준비 audit REPORT.

후보 5 — syndrome에 안전한 조합만 측정하는 부분 uncomputation
---------------------------------------------------------
현재 phase parity gadget의 전체 역회로를 항상 coherent하게 실행할 필요가
있는지 묻는다. 공통 ancilla parity register a=Lx에 모든 phase를 적용한
다음 invertible binary basis change를 하고, 최종 syndrome·logical frame·
detector signature가 안전한 조합만 MX로 지운다. 위험한 조합은 coherent
uncompute를 유지한다. basis change를 T 이전으로 옮기려면 phase network도
다시 합성해야 한다.

현재 v29의 15개 T/Tdg 축을 개별적으로 조사하면 14개의 측정 byproduct가
최종 syndrome을 바꾼다. 따라서 '역회로 전부 삭제'는 안 된다. 15-rank 같은
형식적인 kernel 차원을 독립적인 ancilla 자유도와 혼동해서도 안 된다.
논리 frame만 남는 경우에도 noisy MX의 오기록이 O(p) 손실을 만들 수 있다.
허용하려면 byproduct가 stabilizer이거나, 오기록이 이후 detector에 걸리거나,
readout을 보호해야 한다.

작은 정확한 witness: u=x0+x1, v=x0+x2, w=x0+x1+x2의 phase 이후
CX(u,v), CX(u,w)로 v=x1+x2, w=x2를 만들고 u만 2CX로 지운다.
v,w를 MX로 지우면 위험한 Z0는 나오지 않는다.
역회로 7CX -> basis2CX+uncompute2CX+2MX. 모든 corrected Kraus 오차 0.
첫 실험: 현재 축을 공통 parity register로 재합성하고, 안전성의 joint map을
최적화한다. 예제의 3CX 절감을 v29의 이득으로 그대로 대입하지 않는다.
증거: architecture/kernel_uncompute.*, evidence/phase_byproducts.json.

후보 6 — Fano 구조를 이용한 선택적 대기 메모리 보호
------------------------------------------------
대기 중인 7개 데이터를 모두 보호하지 말고 1~3개 위치만 보조선으로 phase
오류를 감지한다. helper |+>, CX(h,D), 대기, CX(h,D), MX(h)=+ 조건의
X-repetition wrapper를 쓴다. 데이터당 2CX와 helper 1개다. 이 wrapper는
Z/Y를 검출하지만 X 오류는 더 모을 수 있어, 보호 위치를 선택해야 한다.
Steane의 Fano line 구조상 이상적 wrapper의 저장 cubic loss 계수는
무보호14, 2개 보호10, Fano line 3개 보호10, 7개 전체 보호28이다.

물리 noise를 넣은 별도의 storage toy(최종 6 stabilizer는 이상적 postselect):
  6 tick, 무보호: loss=1.1290174281e-7
  6 tick, 2위치: loss=7.1508708178e-8 (-36.66%), 상대 acceptance=.98834387
  12 tick, line3: loss=9.0869073610e-7 -> 5.5108227240e-7 (-39.35%)
이 수치는 v29 전체 손실 개선율이 아니다. toy의 이상적 마지막 검증을 실제
회로로 바꾸고 교차 오류를 포함해야 한다. v29 acceptance 여유는 작다.
첫 실험: 실제 대기 구간에서 민감한 2개 위치부터 전차수 평가한다. 특히 A의
오류와 데이터 Z 대기의 교차항을 확인한다. 보호가 종료 tick을 늦추거나,
수락률을 .5 아래로 내리거나, 전체 손실을 늘리면 종료한다.
증거: preparation/fano_storage.*, selective_storage.*.

후보 7 — c1=0을 강제하지 않는 유한 p 손실 예산 최적화
--------------------------------------------------
GOAL은 fault_scan c1=0을 비목표/진단으로 명시한다. 그런데 exact2.py의
--third는 abs(loss1)>=1e-12이면 생략한다. 현재 검색의 실질적 금지 조건과
진짜 목표 사이에 틈이 있다.
한정된 유해 single fault를 허용하면서 많은 routing/checking을 없애는
경우를 실제 p=.001에서 비교해야 한다. 무조건 single을 허용하자는 뜻은
아니다. 2큐비트 채널의 한 Pauli가 loss1/2를 내면 leading raw cost만
p/30=3.3333e-5이므로 매우 큰 절감이 없으면 불리하다. 정확히 하나의 오류만
난 accepted 사건의 양의 손실 질량을 하한으로 사용해 초기에 기각한다.

N=n1*p+n2*p^2+n3*p^3+..., A=1+a1*p+a2*p^2+...일 때 3차 계수는
n3-a1*n2+(a1^2-a2)*n1이다. n1=0 전용 공식은 이 검색에 쓸 수 없다.
첫 실험: weighted harmful-single budget를 명시한 합성 + 전차수 평가.
이상적 정확성, grid, acceptance, class 제약은 유지한다. 실제 이득을 주는
nonzero-c1 witness는 아직 발견하지 못했으며 c1 relaxation 자체를 향상으로
주장하지 않는다.
소스: work/lanes/EVAL/exact2.py, docs/GOAL.md.

후보 8 — 유한 p 조건부 손실의 정확한 저차 timing curve
--------------------------------------------------
현재 dloss_dP는 주로 2차 sensitivity다. 고차/acceptance/영역 간 교차항까지
포함하는 목적함수 L=N/A를 직접 최적화한다. gate order, final depth, native
folding, first-use 구조를 고정하고 내부 CX 한 개를 delta tick 이동하면
앞뒤 두 wire의 idle interval 네 개만 변한다.
alpha=1-4p/3, z=alpha^delta로 놓으면 N(z),A(z)는 z^-2..z^2의 Laurent
다항식이다. 따라서 L(z)=P4(z)/Q4(z)이고 derivative numerator degree<=6.
각 timing interval의 끝점, stationary root의 정수 인접 시점, acceptance
경계의 정수 인접 시점만 비교하면 된다. 가까운 loss 표본을 부정확하게
차분/보간하지 말고 contraction environment에서 계수를 직접 구한다.
첫 실험: v29에서 slack이 있는 CX 10~20개에 적용하고 움직임을 합친 뒤
다시 전차수로 평가한다. gate order/folding/reset/종료시각이 바뀌는 경우는
별도 구간/모델로 처리한다. 현재 최적 시각과 모두 같으면 물리 이득이 없는
검색 가속으로만 기록한다. 아직 측정된 회로 성능 향상은 없다.

후보 9 — 희소 kernel 조건화와 detector basis 정리
----------------------------------------------
이미 시도한 'Walsh 평가'의 반복이 아니다. 커밋된 dense 구현이 계산해 놓고
사용하지 않던 kernel_nonzero를 실제 contraction 구조에 사용한다.
Z=E[K(x_K)*product f_c]를
2^(-|K|) sum_{a in supp K} K(a)*E_R[product f_c(a,x_R)]로 계산한다.
19~20개 dense kernel 변수를 sparse selector batch로 바꾸어 큰 clique를
없앤다. v23의 남은 elimination width23->8, v29는26->9다.
v29의 reduced projector38과17은 같으므로 detector38을38 XOR17로 바꾼다.
이는 가역 row operation이며 53개의 물리 오류 검출 조건을 모두 보존한다.
active projector5->4, kernel20->19bits, acceptance support488->244.

실측:
  v23 dense: 260.6876초, 7.02618674069663e-5
  v23 sparse: 18.8716초, 7.02618674070690e-5 (13.8138배)
  v29 sparse: 51.5903초, 6.34391366976559e-5
  v29 sparse+basis: 27.9380초, 6.34391366975465e-5
v23 73개 contraction 최대 차이2.78e-16. v29 row 정리 전후 loss 차이1.10e-16.
v29의 최대 개별 bucket은1,173,504 float64, 약9.39MB이며 전체 RSS가 아니다.
Fourier cutoff 손실 기여 상한약1.06e-14. 이 증명은 roundoff 전체 인증은 아니다.
첫 적용: COMP29/ST2 조합을 전차수로 재순위화하고 finalists만 공식 MC로 확인.
물리 충실도 자체가 이 rewrite만으로 높아지는 것은 아니다.
증거 및 실행: evaluator/README.txt, sparse_walsh.py, receipts/.

후보 10 — 측정 분기까지 포함하는 격자 graph-resource instrument 합성
----------------------------------------------------------------
가장 탐색적인 후보다. 이미 선택한 encoder interaction graph를 routing하는
대신, local-Clifford equivalent graph들과 Pauli 측정 삭제를 이용해 격자
resource 자체를 합성한다. 출력 resource와 그 resource를 소비하는 check를
함께 목표로 하며 측정 분기 부수 효과를 실제 최종 detector/frame으로 제한한다.

실제 탐색: Steane |0_L>의 labeled LC orbit532개, unlabeled9종, 최소9edges.
작은 full2x4/3x3/2x5 cluster에서는 정한 측정 패턴 내 witness가 없었다.
3x4, 17edge cluster의 5개 X/Z 측정 25,344패턴에는 unsigned graph
witness54개가 있었다. 하지만 unsigned stabilizer 일치만으로는 부족했다.
별도의 native CSS 검사에서는 unsigned Steane0 패턴27개 중 허용된 Z
byproduct(알려진 logical X 포함)만 남는 것이0개였다.
따라서 '17CX cluster로 B 준비 완료'라는 결론은 틀리다.

새 search에는 처음부터 resource의 소비/측정 및 부수 효과의 affine
전파식을 넣는다. local Clifford, readout, coherent repair의 비용도 포함한다.
기존 joint prep+check와의 차이는 합성 공간 자체를 encoder DAG에서
measurement graph instrument로 바꾸는 데 있다.
첫 실험: 작은 patch 하나에서 모든 branch를 충족하는 합법적 gadget을
찾고 noisy fault를 계산한다. 남은 물리 data correction을 logical frame으로
위장하지 않는다. 분기 조건에서 계속 실패하면 더 큰 routing 탐색을 시작하지
않는다. 이상적 합법 witness가 아직 없으므로 우선순위는 가장 낮다.
증거: architecture/graph_search.*, cluster_search.*, css_cluster_frames.*.

추천에서 뺀 접근
---------------
* 단순 detector coset 추가 수락+논리 frame: v29의 449개 first-order-safe
  nonidentity-frame 정책이 전부 distinct-channel two-fault screen에서 불리했다.
  이것은 모든 비선형 정책의 불가능성 증명이 아니라 검사한 1차원 kernel
  확장 집합에 대한 결과다.
* 개별 phase gadget의 모든 uncompute 삭제: 15개 중14개의 출력 syndrome
  byproduct가 허용되지 않는다.
* 전체7개 데이터의 반복코드 보호: 이상적 storage cubic coefficient14->28,
  noisy12tick toy도 손실이 약30.5% 늘었다.
* 1T/rank5 phase 압축, readout 복제, 초기화 helper 검증, 일반 Walsh contraction:
  이미 저장소에서 시도했거나 채택한 영역이다. 위 목록은 각각 다른 구체적
  메커니즘이 있는 경우에만 포함했다.

실행 순서
---------
즉시: 후보9 evaluator를 기존 variant 순위화에 사용하고 후보7 평가 경로 수정.
큰 물리 개선: 후보1의 비연결 B/C+지연 검증과 후보2의 부분 출력 이동을
하나의 시간별 배치 문제로 구성. 후보3 macro를 encoder library에 추가.
새 계약: 후보4와5를 작은 정확한 instrument부터 합성.
별도 제한 실험: 후보6,8. 후보10은 branch-valid 작은 witness를 먼저 요구.

승격 기준은 이상적 정확성, 6x6 최근접 CX, 실제 STANDARD noise, acceptance
>=.5, 허용된 logical frame, 공식 judge class/runtime이다. grid-free 수치를
유효 점수로 부르거나 2차 개선만으로 승격하지 않는다. 단일 seed의 우연한
낮은 점수와 독립 계산/복수 seed의 기대값 개선을 구분한다.
