3. NEW CONCRETE THREE-PARITY TRACKED-INITIALIZATION EXPERIMENT: NEGATIVE
------------------------------------------------------------------------
The current c272/c16 relation suggests a zero-extra-quantum-gate record policy.
I constructed and fully priced it rather than assuming it works.

Exact propagation of a real Z8 sign error immediately after MX8(c272) gives:
  flipped measurement bits: {16,29,30,32}
  flipped existing detector rows:19 and69
  output physical Z support: {3,7,20}, code indices{1,2,4}
The output error differs from single Z on codeindex3 by the Z stabilizer
support{1,2,3,4}; the fixed judge decoder corrects it.

The experimental policy changes only DETECTOR declarations:
  remove singleton detector c272;
  replace row19 by c31 XOR c32 XOR c33 XOR c34 XOR c260 XOR c272;
  replace row69 by c16 XOR c272.
This accepts the old sector plus a tracked initialization-sign sector. It
adds no gates and uses no unallowed physical-qubit FRAME extension. Official
FRAME declarations are logical X/Z, not arbitrary physical corrections.

Initial checks:
  ideal acceptance1, ideal decoded loss0;
  all six ideal output stabilizers equal1 BEFORE the fixed judge decoder;
  ideal logical X=+1/sqrt(2), Y=-1/sqrt(2), also before that decoder;
  no harmful single fault above1e-15; numerical first-order residual3.09e-19;
  same206CX, depth47 and native schedule.

Full73-moment all-orders result with finite-p channels:
  conditional loss       5.518914727407511e-5
  acceptance              0.5022404149733369
  channels                539
  evaluator wall time     35.29s
  kernel omission bound   1.194e-14 (excludes floating-point roundoff)

Relative to current v35a the policy gains acceptance0.00100347635 but worsens
loss25.6147%. The newly accepted sector alone has conditional loss
0.00567650310. Therefore this concrete policy is CLOSED and must not be
promoted, described as an improvement, or sent for expensive Monte Carlo.
It is a clean example of why zero first-order loss is insufficient.

The root's narrower two-bit oracle, keeping row19 at zero, is also negative:
c16 XOR c272 alone yields4.487635477e-5. That is a different policy; it does
not include the B-syndrome offset tested here.

Broader method that remains open: optimize a JOINT affine detector row-space
and logical frame over A initialization/terminal records and B/C records,
instead of merely deleting detectors or changing a quantum readout circuit.
First run an optimistic sectorwise oracle with arbitrary accept/reject and the
best logical Pauli per sector. If even that relaxed oracle cannot improve at
the required acceptance, close the selected record set without any physical
compiler work. Only an oracle margin justifies optimizing legal affine Hm=b
and logical frame Fm+c. The small negative examples above are evidence for
this early rejection gate; they are not evidence for guaranteed benefit of
the larger domain. Existing BCFB/COMP29 mixed-basis circuit work is distinct.

--------------------------------------------------------------
PLAN line63 still rejects any c1!=0 using a universal p/30 minimum for one
harmful D2 Pauli. That minimum is false. The exact review7 cyclotomic witness
has a physical single-fault branch accepted with mass1/4 and conditional loss
1/2, giving p/120=8.333333e-6 atp=.001. The full witness circuit is legal and

Use the true accepted branch mass and loss, then a finite-p event lower bound,
to reject c1-nonzero proposals. The review7 finite_p_guard algebra remains
valid for independent effective channels. Its current floating implementation
is a numerical screening calculation, not an interval certificate.

This does not reopen below1e-5 under the standard rules. The separate retained-
output-channel proof, including output-output CX, branch selection, logical
frames, first use/reset, and arbitrary preceding quantum states, still gives
the rigorously rounded-down lower bound1.1620296389e-5. Its exact rational
comparison was rechecked in audit/review7_objective/bound_recheck.json. No new
rule or v35a change affects those terminal assumptions. Avoid conflating the
false per-fault quantization with this different global lower bound.
