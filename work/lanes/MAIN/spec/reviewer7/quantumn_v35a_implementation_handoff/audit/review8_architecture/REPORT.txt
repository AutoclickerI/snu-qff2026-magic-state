CONCLUSION
----------
The current v35a baseline remains the lowest-loss circuit among the eight
complete circuits in this bounded study. The old review7 improvement must
not be represented as a new improvement over v35a: v35a already incorporates
the A decoder, uses a different A encoder/schedule and guard set, and ends
one native tick earlier than the old baseline.

Two useful budget seeds were established quantitatively. Removing the q20
X guard releases acceptance 0.0083520 for loss cost 2.60592e-7. Exchanging
two C readout copies for one readout-encoding CX releases acceptance
0.0024127 for loss cost 1.03012e-7. Neither is itself a loss improvement;
their value depends on a subsequent check using that budget productively.

The old CX28->29 readout edge cannot be appended for free on this schedule.
Keeping the existing copies requires an additional terminal tick and more
than doubles the loss in the fully noisy constructed circuit. This closes
that precise transplant; it is not a general bound on C readout synthesis.

Complete guard definitions (ticks are zero-based):
  Z on q0:  RX q6@34; CX6->0@35,@39; MX q6@40 -> c273.
  X on q20: R q19@13; CX20->19@18,@31; M q19@32 -> c274.

The old review7 q20 Z guard through helper26 is not present in v35a.
Confusing it with the current q20 X guard would give the wrong composition.

C-copy exchange:
  Remove R34,R35@44, CX28->34,CX29->35@45, M34(c268),M35(c267)@46,
  and detectors {c27,c268}, {c26,c267}. Insert CX28->29@45.
  Keep both original C measurements at46. For every retained detector that
  contains c26, XOR c27 into its row. This is the exact substitution
  old c26 = new c26 XOR c27, preserving the original C measurement contract.
  The added CX carries DEPOLARIZE2(0.001), confirmed from the native noise
  blocks. The removed copy checks and their physical operations are gone.

Appended-edge control:
  Keep both copies; insert CX28->29@46 and move M28,M29 to47. Apply the same
  invertible detector substitution, including the retained copy checks.
  It charges both the added noisy CX and the additional terminal idle tick.
  The +111.3011% is the whole construction's measured model penalty, not a
  separately isolated idle-only attribution.

PARETO INFORMATION, NOT AN IMPROVEMENT CLAIM
------------------------------------------
Relative to v35a:
  Drop Zq0: loss +2.48722e-7 (+0.56611%), acceptance +0.00245008.
  Drop Xq20: loss +2.60592e-7 (+0.59313%), acceptance +0.00835202.
  C-copy exchange: loss +1.03012e-7 (+0.23446%), acceptance +0.00241267.

At equal 204-CX/47-tick cost, Xq20 removal dominates removal of Xq7, Xq10
and Xq4 in both loss and acceptance. Zq0 removal has slightly lower loss
and substantially less acceptance than Xq20 removal. The C-copy exchange
offers a lower-loss, smaller-budget alternative at 205 CX. A future joint
check selection must recompute actual compositions because error mechanisms
and acceptance costs need not add independently.
