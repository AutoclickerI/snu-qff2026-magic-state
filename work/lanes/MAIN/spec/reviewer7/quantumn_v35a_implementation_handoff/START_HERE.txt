====================================

This archive is the complete reviewed evidence package plus an actionable
implementation brief. It is intended to be usable without the chat history.
It contains the full English report, the original Korean report, ten task
specifications, source snapshots, actual circuits, proofs, negative results,
an evaluator, pinned official judge sources, and completed validation receipts.

IMPORTANT EXECUTION LIMITS
-------------------------
The existing official runner can exit 0 even when a gate fails or an exception
is written to its receipt. Check the final JSON, expected circuit hash, shots,
seed and judge pin. check_official_receipt.py automates that consistency check;
it does not replace the official judge or prove a receipt's authenticity.
For a fresh run, require both process exit code 0 and a newly generated final
receipt. Rename the old expected receipt before starting in the working copy:
an early failure can leave a stale passing receipt untouched.

Use unique candidate basenames. Several supplied scripts write output beside
the evaluator using only the candidate basename and can overwrite receipts.
Preserve this evidence archive and run experiments in a separate working copy.

The pinned reproduction environment is Python 3.12 / Linux x86_64. Installing
the pinned dependencies requires network access. Wheels and a virtual
environment are not included. The sparse evaluator has a narrower supported
class than the actual competition; unsupported does not mean illegal.

The full EXENC search engine and historical path cache are NOT in this ZIP.
The included EXENC source extract supports the objective certificate. M01's
full search needs exact.cpp, DR/prepA_L5_s7307.json, and historical paths/cache
from the implementation checkout or a regenerated equivalent. The local
certificate itself remains reproducible without those missing search assets.

The sub-1e-5 question is addressed in REPORT_EN.txt and
audit/subthreshold_bound/PROOF.txt. Under the inspected STANDARD model, the
retained-output-channel argument gives a safely rounded expected-loss bound
L >= 1.162e-5. A weaker bound below 1e-5 is not an achievable construction.
Changing that conclusion requires identifying a failed proof assumption,
an actual model change, or a valid counterexample—not merely a low MC draw.
