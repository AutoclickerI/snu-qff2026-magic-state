## Item 10 — boundary cache API

Both cubic and all-orders caches are implemented. Original BC boundary rank is 11 = 8 X + 3 Z, hence 2048 classes. Adding C checks changes the suffix and can increase that rank; it requires a new cache. Full cache contraction retains the relevant boundary detector Fourier variables, then combines their Walsh transform with decoder characters to produce every `(N_k,A_k)`. Scoring is exactly `sum(P_k*N_k)/sum(P_k*A_k)`.

```python
import os, sys
os.environ["XTIM_TWIRL_CACHE_DIR"] = "/absolute/path/to/your_lane/.xtim_cache"
sys.path.insert(0, "/home/jihoon/competitions/quantumn/work/lanes/BCPOL")
from boundary_api import prepare_candidate, AllOrdersCache

region = prepare_candidate(
    "/home/jihoon/competitions/quantumn/work/lanes/BCPOL/inputs/"
    "cache_rank4_3_after_check")  # replace with an audited candidate stem
cache = AllOrdersCache(
    "/home/jihoon/competitions/quantumn/work/lanes/BCPOL/inputs/"
    "cache_rank4_3_after_check.boundary_allorders.npz")
result = cache.score(region)  # loss, numerator, acceptance, score_seconds
```

Inputs are a QASM and sibling JSON with `data_qubits` and `R`. `boundary_step` optionally selects the cut independently of R; the cut is **before** that native step, whose operations belong to the exterior. Operations before the cut must form a chronological native-step program prefix; interleaved cuts are rejected explicitly. `region_qubits` optionally replaces the ordered BC-qubit list. `init_times` can specify the region’s initial operations; otherwise they are derived from the native circuit. The original caches cut before R, so any joint-prep/check operations at R remain exterior. A cut after the joint check requires recompilation. The winning rank-4 cache is `inputs/cache_rank4_3_after_check.boundary_allorders.npz`, paired with its QASM/JSON alias of rank4_3_00731. Its metadata sets boundary_step=49 (R+1), enclosing the complete joint check. It has 8192 classes (rank 13), 130 region channels, and width 26; compilation took 766.9 s with four processes. Its public API median is 0.0570 s per score, measured over 12 calls; its full-evaluator loss difference is 3.2e-16. The original 2^11 bound applies to the original detector contract; extra endpoint checks enlarge the sufficient boundary signature.

`prepare_candidate` runs full-model extraction in an isolated process, preventing module-name collisions with another lane. This audit/model build is outside the fast scoring time. It returns `PreparedRegion(fingerprint, channels, n_classes)`. The cache arrays store the unconditional accepted-infidelity numerator N_k and acceptance A_k for an injected boundary class and all exterior noise. `score` forms the XOR distribution P_k from the independent categorical region channels, then computes the conditional ratio. Each channel is a tuple of `(class_index, probability)` outcomes, with no-fault probability `1-sum(p)`. Keep mutually exclusive outcomes in one channel. A search that already propagates region channels can construct this object directly using the audited mapping and fingerprint.

The SHA-256 fingerprint covers the entire exterior categorical-channel distribution, reduced ideal rotations/projectors/decoder operators and reference signs, and ordered boundary basis. The exterior includes prefix, data and A noise, not just the late suffix. Shared-record correlations therefore remain represented. Cache reuse requires exact equality; mismatches raise ValueError. Changes to exterior noise, initialization policy/timing, ideal endpoint, measurement basis or boundary mapping can require a new cache. Do not copy a desired cache fingerprint onto an unaudited rewrite.

`AllOrdersCache.score` checks the fingerprint, dimension, categorical probabilities and transformed normalization, and includes all noise orders. `CubicCache` uses `boundary.cache.npz`, requires |c1|<1e-12, and returns second/third/total plus exp(−A1). The latter is a screen, not an all-orders value. Compilation commands are `cache.py <stem>` and `cache_allorders.py <stem> --procs N`; output locations must be writable by the caller. Current guards are boundary rank ≤14, all-orders contraction width ≤26, rotation rank ≤5, at most 15 rotation signs, and at most nine retained boundary detector Fourier variables for cache compilation; unsupported instances fail explicitly. Cache scores do not replace judge format/ideal checks, seed-0 acceptance, or measured runtime gates.

Measured hot path: roughly **0.01–0.02 s** for the validated 2048-class all-orders caches. The v23 cache compiles in 475 s at width 23; its baseline/full difference is 6.6e-17. Physical cancellation and inserted-identity controls independently agree within 5.2e-17. The v25 cache compiled at width 26 and agrees with the independent full contraction within 4.0e-16. The rank-5 extra-check cache and its reference circuit are retained as `inputs/cache_rank5_parity.*`. Incompatible endpoints are explicitly rejected. Cold model preparation and compilation are excluded from the hot-path number.
