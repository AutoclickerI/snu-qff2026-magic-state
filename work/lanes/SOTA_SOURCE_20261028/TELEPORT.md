# Source-output teleportation: audit and physical counterexample

The judge accepts affine logical `FRAME_X` / `FRAME_Z` declarations. Therefore a random encoded Bell-measurement bit need not be postselected: it can be retained as a logical frame. Arbitrary physical-qubit frames are a different issue, because raw output must be in the Steane code space before ideal decoding. A per-site teleport with independently random physical corrections cannot simply be relabeled as one logical frame.

One-bit encoded teleportation can relocate the entire source block to a new seven-qubit footprint. Prepare the destination in `|+_L>`, apply transversal CX from destination to source, measure the source in Z, retain the measured Steane parity checks, and use the parity of the seven reads as `FRAME_X`. The circuit changes which physical seven qubits are output, so the destination can be selected jointly with its factory and final check geometry. A logical frame avoids the 1/2 ideal acceptance loss that would result from postselecting the teleportation bit.

We built one complete abstract control in `teleport/source_to_fresh_plus.qasm` and `.json`, generated by `teleport_probe.py`. It uses the actual noisy v37j source, an explicit generic noisy nine-CX `|+_L>` encoder, the seven actual teleport CX gates, Z reads and the frame. The seven final CX edges are local for this selected footprint, but the generic resource encoder is nonlocal; the whole circuit is therefore diagnostic, not a valid grid submission. It passes the raw target check with the affine frame. Its exact full-noise result is **L=0.00103241383309**, **A=0.61345949035**. Seven harmful single-fault components occur in the unverified `|+_L>` encoder; their summed first-order loss at p=0.001 is **4.66666667e-4**. Full frame-aware results and component labels are in `teleport/source_to_fresh_plus.result.json`.

The tested control therefore fails decisively before routing. It does not exclude a separately verified or jointly prepared destination block: those changes alter the accepted resource-error distribution and must be priced with every preparation channel. In particular, Z faults on the incoming source can propagate through the teleport into the output, so removing the old terminal apparatus does not automatically preserve its source checking.

The final transversal teleport gate leaves each output coupled to a partner subsequently measured. That is within the repository's measured-partner terminal class, whose documented ideal class floor is approximately **2.274e-5** at p=0.001. Thus relocation through this one-bit primitive alone does not access the approximately **2.189e-5** broader all-circuit floor. It can still change preparation cost and the incoming fault distribution; those effects require a full physical instrument and cannot be inferred from the floor.

A more ambitious source-and-terminal co-design could directly prepare a state already encoded across seven four-qubit tiles, leaving an unmeasured helper on each final output at the last layer. The documented perfect-input C4 contraction reaches **2.192096e-5**, but its tested noisy preparations are much worse, and the project found that none of 242 fixed tile packings left all eight spare cells both connected and adjacent to every tile. Those are scoped findings, not an impossibility for time-shared or jointly prepared resources. The present lane has no concrete native implementation with a competitive full-noise score, so there is no justified new submission candidate from this idea.
