# Source and reproduction notes

The reference judge, qtools and shared `.venv` are those pinned by the parent repository; the lane does not modify them. All quoted SpiderCSS/ULO candidates are abstract-connectivity diagnostics, not grid-valid submissions. Exact outputs in the saved receipts include physical reset, gate, measurement and waiting channels.

## External research

- [SpiderCSS](https://github.com/boldar99/spidercss), commit `fb1d58ded2b54358ef00504324f52bda472cdffa`, Apache-2.0; see [paper arXiv:2610.03714](https://arxiv.org/abs/2610.03714). `spider_bc85.py` generates the mask-85 24-CX netlist preserved in `spider_bc85.log` (SHA-256 `394088c095f2613970de60b95b9bec458b2c383456421e8d21c422e4049258dd`). `spider_bc85_check.py` verifies its full state.
- [SpiderCat](https://github.com/boldar99/spidercat), commit `bb2cc05fface45d9e5b2dbc5d1464026f91a52ac`, Apache-2.0, required by the compiler.
- [Steane-Ultra-Low-Overhead](https://github.com/boldar99/Steane-Ultra-Low-Overhead), commit `77a0f36f10d881c599e0cc11381fcdd7b07aad46`; repository does not declare a license in its checked tree. See [paper arXiv:2511.13700](https://arxiv.org/abs/2511.13700). The reviewed file `simulations/dynamic_floqetified_stean.py` at that commit has SHA-256 `4d708a9748a4513a021e4e5d2fabfe06cac92094cae311acb5e75f5951a9d221`; retrieve it from `https://raw.githubusercontent.com/boldar99/Steane-Ultra-Low-Overhead/77a0f36f10d881c599e0cc11381fcdd7b07aad46/simulations/dynamic_floqetified_stean.py`. The unlicensed third-party source is excluded from this checkpoint; `ulo_insert.py` implements its published 14-CX instrument for this diagnostic.

For an isolated compiler setup, create a lane-local dependency target with the repository's `.venv/bin/python -m pip install --target <isolated-dir> --no-deps` for `networkx==3.7 pyzx==0.10.7 galois==0.4.11 python-sat==1.9.dev17 lark==1.3.1 pyperclip==1.11.0 numba==0.68.0 llvmlite==0.50.0 tqdm==4.70.1`, then install `mypy==2.4.0` with its normal dependencies and `git+https://github.com/boldar99/spidercat.git@bb2cc05fface45d9e5b2dbc5d1464026f91a52ac` with `--no-deps`. Check out SpiderCSS at the commit above; put both that checkout and the target directory on `PYTHONPATH`. Use one CPU and set `OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1`. No downloaded source, dependency tree or virtualenv is part of the publication manifest.

The best ULO complete circuit is `ulo_schedule/deep_005` (QASM SHA-256 `1aaddaee6055620471d45819fede422874741b574d3b0ea63e0dc26e699e1bed`); its `.exact.json` records L=2.9649858252424977e-5, A=0.640392636273766. The best seven-cat-only circuit is `deep_extra_best/flag_9_0_5` (QASM SHA-256 `f2ea2519aafa5a2de189d35ec0fef3db6677bdd5de1869b126b0edc3dcecd337`), L=2.9720782263202955e-5, A=0.7081682122007729.
